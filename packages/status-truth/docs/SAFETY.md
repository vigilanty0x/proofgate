# Public safety boundary

All examples and tests use synthetic service names and synthetic observations. The
project contains no account identifiers, private repository references, tokens,
network addresses, production telemetry, or customer data. The CLI performs no
network calls. It reads one bounded JSON file and writes one caller-selected journal.

Diagnostic and metadata text may be displayed by downstream dashboards. Consumers
should escape it for their output context. Do not place credentials or personal data
in evidence, references, diagnostics, or metadata.
